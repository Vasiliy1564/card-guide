# Карта для зарубежных подписок и покупок

Независимая русскоязычная партнёрская страница о ZARUB.

Статический сайт: HTML, CSS и JavaScript. Серверная часть и сборка не нужны.

## Публикация
GitHub Pages: ветка `main`, папка `/ (root)`. Все пути к ресурсам относительные.

## Структура
- `index.html` — главная страница.
- `assets/site.css` — адаптивное оформление, включая встроенные шрифты.
- `assets/site.js` — калькулятор расходов.
- `assets/favicon.svg` — иконка.
- `sitemap.xml`, `robots.txt` — файлы для поисковых роботов.
- `404.html` — страница ошибки.

## Реферальные переходы
Все кнопки оформления: https://zarub.io/?ref=wRZ2e0

## Домен
После выбора домена обновить canonical и og:url в index.html, адреса в robots.txt и sitemap.xml, затем подключить домен в Pages и настроить DNS. На GitHub Pages в подпапке robots.txt не является корневым robots.txt хоста; после подключения собственного домена файл станет корневым.

Тарифы на странице требуют периодической сверки с официальным сайтом ZARUB.
